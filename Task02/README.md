## Overview
Task 02 focuses on the architectural and event-driven design for a Hospital Outpatient Appointment desktop application using Java AWT/Swing. In accordance with the assignment requirements, this task is an event-driven analysis, containment modeling, and pseudocode specification rather than a raw code implementation.

## Key Design Deliverables
1. **Event Table:** Mapping of GUI components, event objects, listener interfaces, and concrete actions.
2. **Component Containment Tree:** Hierarchical breakdown of Swing containers, panels, and input components.
3. **Doctor List Refresh Pseudocode:** Department-to-doctor cascading update using an in-memory mapped cache.
4. **Validation and Booking Pseudocode:** Field verification, department matching, slot availability checks, and status feedback.
5. **Window Method-Call Sequence:** Execution flow from `main()` and EDT initialization through user events to disposal.
6. **Lifecycle Comparison:** Comparative analysis of JFrame window events vs. Java Applet lifecycle (`init`, `start`, `paint`, `stop`, `destroy`).
7. **Database vs. Map Architectural Comparison:** Performance, latency, memory overhead, data freshness, and trade-offs.
8. **Complexity Analysis:** Big-O time and space complexity evaluations for lookup, list refresh, and booking validation.
